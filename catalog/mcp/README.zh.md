# Or MCP 推荐

此目录轻量收录适合与 Or 配合使用的 MCP 服务器，帮助用户发现可信的服务、了解其
用途，并在连接前确认所需条件。

这里不是运行时配置目录。每个条目只提供官方来源、常见用途、Or 配置示例、身份
验证要求和必要的安全说明。Or 仍然只从自己的私有 `mcp.json` 配置加载已启用的
服务器。

## 已收录服务器

| 服务器 | 连接方式 | 推荐用途 |
|---|---|---|
| [GitHub](github/README.md) | Streamable HTTP | 仓库、代码搜索、Issue、Pull Request 和工作流 |


## 收录要求

- 每个一级子目录只收录一个服务器。
- 说明服务器提供什么、为什么值得推荐，以及适合在什么场景使用。
- 链接可信的官方来源，并记录文档、许可证和实际审查过的版本。
- 只收录 Or 支持的 stdio 或 Streamable HTTP 配置。
- 配置示例需要兼容 Or，密钥统一使用 `${env:NAME}` 引用。
- 不得包含 token、密码、Cookie、私有服务地址或特定机器的设置。
- 如实说明身份验证、网络访问、本地执行和写入能力；条件允许时优先使用最小权限。
- 添加或连接服务器必须由用户明确操作。
