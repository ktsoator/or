# Or CLI 精选

此目录用于轻量收集适合软件开发和编码智能体使用的命令行工具，帮助用户发现好用的
工具，并快速了解它们为什么值得尝试。

这里不是包管理器或安装器。每个条目只提供简短介绍、官方来源、支持平台、常用示例
和上游安装文档链接。

## 已收录工具

| 工具 | 命令 | 推荐用途 |
|---|---|---|
| [ripgrep](ripgrep/README.md) | `rg` | 快速递归搜索文本和代码 |

## 收录要求

- 每个一级子目录只收录一个工具。
- 说明工具能做什么、推荐理由以及适用场景。
- 提供命令名、支持平台、常用示例、官方仓库、使用文档、安装文档和许可证。
- 优先收录持续维护、相较常见替代方案有明确优势的工具。
- 示例应简短、安全且有代表性；对于明显扩大访问范围或执行其他程序的参数要特别
  说明。
- 链接上游安装文档，不在本仓库维护完整的软件包管理器命令矩阵。
- 不得包含凭据、私有服务地址或机器专属配置。
