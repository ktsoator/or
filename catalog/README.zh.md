# Or 精选目录

`catalog` 的意思是“目录”或“精选集合”。这里统一放置 Or 项目推荐或分发的资源；
它不是运行时配置目录，仅浏览这些文件不会安装或启用任何内容。

## 分类

| 分类 | 内容 | 使用方式 |
|---|---|---|
| [Skills](skills/README.zh.md) | 适合再分发的完整 Agent Skill 包 | 使用前将选中的包安装到标准 `.agents/skills` 目录 |
| [MCP](mcp/README.zh.md) | MCP 服务器推荐及 Or 配置示例 | 检查条目并将配置添加到 Or 后再连接 |
| [CLI](cli/README.zh.md) | 好用命令行工具的轻量推荐 | 需要时按照上游安装文档自行安装 |

每种分类仍然保留自己的格式和收录要求。统一顶层目录只是为了方便发现，并不表示
Skill、MCP 服务器和 CLI 工具有相同的安装方式或安全模型。

## 基本原则

- 优先选择可信的官方上游和持续维护的项目。
- 再分发内容时保留来源、版权声明和许可证。
- 不提交凭据、私有服务地址、本地配置、缓存或生成产物。
- 说明与安全相关的行为；安装软件、启用服务器或执行附带脚本前都必须由用户明确
  确认。
